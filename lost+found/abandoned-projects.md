# 被遗弃的项目

> 每一个消失的仓库，都在提醒我们：开源也需要照顾人。

## 为什么会「消失」

- **维护者倦怠（burnout）**：无偿劳动 + 用户压力 = 倦怠。
- **巴士因子（bus factor）过低**：项目只有一两个核心，一旦离开即停更。
- **资金断裂**：基础设施费用无着落。
- **上游变动**：依赖的项目变更或废弃。

## 著名的「消失」

| 项目 | 结局 |
| --- | --- |
| 大量 Python 小库 | 维护者隐退，留下「依赖地狱」隐患 |
| Flash 替代项目 | 随时代落幕 |
| 诸多个人玩具项目 | 毕业、工作后停更 |

## 如何让项目活下去

1. **降低巴士因子**：文档、新人引导、权限下放。
2. **可持续资金**：Open Collective、GitHub Sponsors、基金会。
3. **明确生命周期**：在 README 写明维护状态与归档政策。
4. **照顾维护者**：社区公约、拒绝无休止的免费索取。
