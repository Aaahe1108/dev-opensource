# 社区：开源的土壤

<LinuxDivider icon="$" />

开源不只是代码，更是由开发者、用户与维护者构成的社区。

## 核心理念

- **尽早发布、频繁发布（Release Early, Release Often）**：让用户尽早参与，让反馈尽早到来。
- **对事不对人**：讨论围绕代码与问题，而非身份。
- **透明决策**：邮件列表、Issue、RFC 公开讨论。

## 贡献不止写代码

| 贡献方式 | 说明 |
| --- | --- |
| 文档 | 翻译、勘误、示例 |
| 测试 | 报告可复现的 Bug |
| 社区 | 回答新人的问题 |
| 设计 | UI/Logo/用户体验 |

## 健康社区的标志

- 有行为准则（Code of Conduct）
- 有新人引导（good first issue）
- 维护者不倦怠：轮换、资助、休息

> 「每一个成功的开源项目背后，都有一个懂得照顾人的社区。」
