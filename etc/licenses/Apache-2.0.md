# Apache License 2.0

> 企业友好的宽松许可证，自带专利授权。

## 与 MIT 的区别

| 维度 | MIT | Apache-2.0 |
| --- | --- | --- |
| 长度 | ~170 词 | 约 11K |
| 专利授权 | 无 | 明确授予 |
| 商标保护 | 无 | 有条款 |
| 修改声明 | 无要求 | 需标注修改 |

## 专利条款为什么重要

贡献者自动向使用者授予**专利许可**，大幅降低专利诉讼风险——这对企业级项目（如 Kubernetes）至关重要。

## 代表项目

Apache HTTP Server、Kubernetes、Android、Swift、TensorFlow。
