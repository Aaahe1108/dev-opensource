# 发行版图鉴

这里收藏了主流发行版的档案，可按家族筛选。每个发行版都体现了不同的开源理念与工程取舍。

<DistroFilter />

## 家族速览

- **Debian 系**：Debian → Ubuntu → Linux Mint，稳定与庞大的软件仓库。
- **Red Hat 系**：RHEL ← Fedora ← CentOS Stream，企业级生态。
- **Arch 系**：Arch → Manjaro，滚动更新与 KISS 哲学。
- **独立**：Gentoo（源码编译）、openSUSE（YaST）、NixOS（函数式配置）。
